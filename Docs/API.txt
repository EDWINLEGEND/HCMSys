11. Save Leave Transactions
Save opening leaves, eligibility and adjustments
Endpoint

POST /api/Leaves/SaveLeaveTransaction

Authorization
Bearer Token Required

Request Header

Authorization: Bearer {token}
Content-Type: application/json


Request Body




Leaves text should be
[{"iEmployeeId":36,"iLeaveTypeId":8,"iAdjType":1,"fDuration":180,"sRemarks":"Sick
Leave"},{"iEmployeeId":36,"iLeaveTypeId":7,"iAdjType":1,"fDuration":35.5,"sRemarks":"Annual
Leave"}]
Note:

You can use the same api to save leave eligibility and leave adjustments. If you have – leave in
adjustment pass iAdjType=-1 or for all + values keep iAdjType to 1
For leave opening leaves - iTransTypeId =0
For leave leaves adjustments - iTransTypeId =1
For leave leaves adjustments - iTransTypeId =2
